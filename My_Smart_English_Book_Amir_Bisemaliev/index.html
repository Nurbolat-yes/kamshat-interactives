ABOUT THE PROJECT

Simple, safe and useful for Grade 3

The project combines visual support, clear audio, repetition and short self-check tasks in one predictable learning sequence.

🎯

Aim

Design a simple interactive electronic English book for a Grade 3 learner and functionally test one prototype page.

👀

Visual support

Each word is shown with one clear cartoon picture so the meaning is easy to recognize.

🔊

Listen & repeat

The learner hears one word at a time, repeats it aloud, then continues to the short task.

🛡️

Safety

No registration, no advertising, no personal-data form, and no compulsory microphone access.

PROJECT RESULTS

What was functionally tested

The project does not invent survey percentages. It evaluates the prototype through functional criteria.

✓ OpensPage/file opens correctly
✓ VisibleTopic and words are readable
✓ ListenOne audio action matches one word
✓ QuizCorrect and incorrect answers are distinguished
✓ RetryAnother attempt is available
✓ HomeNavigation returns to the start
✓ PrivacyNo personal data is requested
✓ No adsNo unnecessary advertising or external links
CONCLUSION

Bright, but still easy to learn from

Simple navigation

Large buttons, short instructions and the same action order help a Grade 3 learner understand the page independently.

Cartoon visuals

Bright animal illustrations make the page friendly without hiding the English word or the learning task.

Next step
